# Трекер тренировок и привычек

PWA для iPhone: тренировки (подходы×повторы + кардио), привычки со стриками, вес,
счётчики и собственные челленджи. Данные хранятся в самом телефоне,
работает офлайн, бэкенд не нужен.

## Новый режим

Личные счётчики Артёма сохранены: без алкоголя с 27.09.2025 и без спреев
с 02.05.2026 — 374 и 157 дней на 06.10.2026. Они продолжают расти каждый день.

Главный экран — ежедневные задачи: 30 отжиманий, 50 упражнений на пресс,
шахматы, французский и чтение. Медитация — минимум 3 дня за неделю
(понедельник–воскресенье); можно отметить любой прошедший день недели.
Будущие дни доступны для просмотра, отметки открываются в соответствующий день.
В настройках у каждой привычки можно изменить название, частоту и недельную цель.

Старый челлендж «75» архивируется при первом запуске новой версии и убирается
из активных карточек; история остаётся в бэкапе. Миграция сохраняет ID и отметки
существующих привычек и применяется один раз, в том числе при импорте и синхронизации.
Новый челлендж создаётся отдельно, со своими правилами.
Экспорт, импорт и настройка синхронизации доступны в настройках.

## Карта прогресса

Во вкладке **Прогресс → Карта** находится большая плоская карта (по умолчанию 400 клеток). Выбери все
повторы, отдельное упражнение, привычку или челлендж. Карта учитывает всю историю
до сегодняшнего дня, независимо от периода недельной/месячной статистики.

- 1 повтор открывает 1 клетку; вес снаряда не влияет на число клеток.
- 1 кардиозапись с заполненным результатом или 1 отмеченный день открывает 10 клеток.
- В клетках постепенно проявляется рисунок или фраза. Завершённые карты доступны
  по стрелкам; остаток переносится на следующую карту.
- Исправление или удаление записи пересчитывает прогресс. Пропуски его не обнуляют.
- Выбор источника и оформления сохраняется на устройстве. Сами клетки вычисляются
  из записей, поэтому импорт и синхронизация не начисляют их повторно.
- **Размер клеток**: крупные (12×12), средние (20×20) или мелкие (28×28).
  Вместимость карты меняется, а накопленные повторы распределяются по новой сетке.
- **Фраза → Своя фраза**: можно сохранить текст до 30 символов с пробелами отдельно
  для каждого источника. Счётчик показывает длину; слишком длинный текст не сохраняется.
  «Автофразы» возвращает стандартные фразы. Черновик не теряется при смене размера.

Каждая клетка открывает свой фрагмент исходного рисунка, сохраняя его детали.
Исходный рисунок: `assets/progress/summit.png` (imagegen); он сохраняется в офлайн-кэш.
Палитра 20×20 в `src/progress-art.js` используется как резервный цвет клеток.
Фразы набираются обычным шрифтом с переносами и открываются фрагментами через сетку;
модуль `src/map-phrases.js` ограничивает длину и экранирует пользовательский текст.
При открытии карты анимация не повторяется: плавно появляются только новые клетки.
Графики и выбор периода находятся в соседнем табе **Статистика**.

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub и запушить эту папку.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Открыть выданный URL на iPhone в Safari → «Поделиться» → «На экран Домой».

Теперь иконка на домашнем экране открывает приложение в полноэкранном режиме, работает офлайн.

## Бэкап

Данные лежат в браузере, поэтому раз в неделю заходи в **Настройки → Экспорт** и
сохраняй файл (например, в iCloud). Восстановление — **Настройки → Импорт**.

## Синхронизация с сервером (опционально)

Можно хранить данные в облаке (на своём сервере) и синхронизировать между устройствами.
Бэкенд — лёгкий Node+SQLite-сервис в папке [`server/`](server/README.md), без внешних зависимостей.

1. Развернуть `server/` по инструкции [server/README.md](server/README.md) (без поддомена — через путь `/trackerapi/`).
2. В приложении: **Настройки → Синхронизация** → ввести адрес API и ключ.
3. Дальше изменения сами уходят на сервер; localStorage остаётся офлайн-кэшем.
   Очистил Safari или сменил телефон — после ввода ключа данные подтянутся обратно.
